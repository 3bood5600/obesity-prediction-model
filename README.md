# Obesity Prediction Model

## Description
This project aims to predict obesity levels in individuals using machine learning techniques. Leveraging various health metrics, the model provides insights into obesity risks and helps in formulating strategies for prevention.

## Installation
To set up the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/3bood5600/obesity-prediction-model.git
   ```
2. Navigate to the project directory:
   ```bash
   cd obesity-prediction-model
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
To use the model, follow these steps:

1. Prepare your dataset in the required format (CSV).
2. Run the training script:
   ```bash
   python train_model.py
   ```
3. Use the prediction script to predict obesity levels:
   ```bash
   python predict.py --input your_data.csv
   ```
